# Proyekto Kanban Skill

A public, model-agnostic skill for AI agents that need to read or safely update Proyekto project boards.

## Files

- [SKILL.md](SKILL.md) — instructions for agents managing a Proyekto `KANBAN.md`.
- [KANBAN format guide](docs/KANBAN_FORMAT.md) — field and synchronization details.
- [Starter KANBAN.md template](docs/KANBAN_TEMPLATE.md) — managed markers, resources, responsibilities, and tags.

## Share and use

- [View SKILL.md](https://github.com/hardc0l2e/proyekto-skill/blob/main/SKILL.md)
- [Raw SKILL.md](https://raw.githubusercontent.com/hardc0l2e/proyekto-skill/main/SKILL.md)

An AI agent can read the raw skill directly, or you can copy `SKILL.md` into the agent's supported skills directory. For a specific project, also give the agent access to that project's repository and ask it to read the target `KANBAN.md` before making changes.
